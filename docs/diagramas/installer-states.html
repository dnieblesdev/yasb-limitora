How responsibility survives interruption

Persistent artifacts outlive setup; transaction ownership flags do not. This state machine describes source guards, not a durable recovery protocol.

No durable journal and no automatic crash resume.

Artifacts and responsibility after interruption

APP denotes the canonical installation directory, not a new configurable route.

Recovery guards are not guarantees

Uninstaller launch failure or nonzero exit logs and continues filesystem rollback.

Zero exit enables a bounded cleanup wait; APP still present after that wait aborts rollback.

Quarantine failure exits before moving prior bytes. Restore failure may attempt to rename the owned quarantine back. Post-restore quarantine cleanup failure exits before prior registry import.

On successful commit, checked old-directory deletion precedes snapshot deletion and clearing live ownership. Post-commit assistance failure is not native installer rollback.
