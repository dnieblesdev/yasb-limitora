## Execution rules

- This plan has **17 implementation slices (S01, S02a, S02b, S03–S15, with boundary S04 split into the separate S04a and S04c review units) and one verification/closeout work unit (S16)**. Each implementation slice is one autonomous review unit and must remain at or below **400 authored changed lines** (additions plus deletions). Stop and open the next named implementation slice before exceeding the budget; do not combine slices for convenience.
- The user's original **S02 authorization covers S02a and S02b only**. It does not authorize automatic chaining or execution of G1; obtain a decision before starting another named unit or any gate.
- Every implementation slice follows strict TDD: **RED** focused failing test → **GREEN** smallest passing implementation → **TRIANGULATE** independent edge/failure case → **REFACTOR** focused rerun. Run `python -m pytest -q --strict-markers` after focused tests; run `python -m pytest -q --strict-markers tests/test_windows_native_proof.py` where runnable, otherwise record `unrun (external)`. **S16 is verification/closeout only: TDD is explicitly N/A; it records the required verification evidence and does not claim RED/GREEN/TRIANGULATE/REFACTOR work.**
- Keep tests and implementation in the same slice. Do not add a public CLI flag, second stdout contract, portable ZIP, public `-rc` tag/version, provider logic, secrets, elevation, YASB lifecycle control, or YASB YAML/CSS edits.
- External gates are only `pass`, `fail`, or `unrun (external)`. `fail` or `unrun` is never represented as passed. All required pre-publication gates must pass before publication.
- The gate branches are exact: **G1:** `S02b → G1 → S10` (and G1 also blocks S11/publication). **Overall G2:** `S02b + S04a → G2a feasibility/selection → S10 static installer path/identity contract when needed → S04c bounded adoption → later installer/build slices → exact retained candidate → G2b installed-candidate confirmation`. G2a `fail`/`unrun` blocks S04c; only G2b `pass` closes overall G2 and permits publication. G1 and G2 have no inferred pass ordering beyond those dependencies.
